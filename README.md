# 🌍 AIWA Web Command（欧州・地中海 国家運営＆戦術ウォーゲーム）

Discordの「AIWA」サーバーで行われている国家運営・軍備編成・外交・戦争シミュレーションをブラウザ上で遊べる統合Webアプリケーションです。

## 🚀 起動方法（Windows）

1. ZIPを展開し、フォルダ内の **`start_web_game.bat`** をダブルクリックします。
   - 初回起動時は自動的にPython仮想環境（`.venv`）と `aiohttp` がセットアップされます（Python 3.10以上が必要）。
2. 自動的にブラウザで **`http://localhost:8085`** が開きます。

## ✨ 主な機能

1. **🌍 平時マップ（欧州・地中海 領土・建国・ワープ）**
   - 欧州＋地中海沿岸（全102プロビンス）の領土確認、白地購入（1プロビ100億・最大10プロビ）、同盟国・通行権保有国への平時ワープ。
   - 空きプロビンスに「首都1つ＋主要都市2つ（陸続き）」を指定して新規建国（初期資金5兆円）。
   - ワンクリックで領土を塗り替えられるバケツ塗りモード搭載。
2. **⚔️ 戦時マップ（平時マップから分離された戦術作戦ボード ＆ AI審判）**
   - `map.army` / `tactrace` 風の戦術ボード上でNATO兵科シンボルのドラッグ配置や、進撃矢印・防衛線・強襲揚陸線の自由描画が可能。
   - `.milxyz.json` 作戦ファイルの保存・読込に対応。
   - **🤖 AI自動作戦立案** および **⚖️ ハイブリッド戦争審判（制空・制海・軍港有無・揚陸船団枠・地上突破・無条件降伏・講和条件上限算出）** を搭載。
3. **🛡️ 軍備編成・師団ビルダー・値段表ショップ**
   - 基幹連隊（3〜4個）＋砲兵連隊（1個まで）＋補助大隊（4個まで）のオリジナル師団設計。
   - 戦車大隊（76両×単価＋10億）・戦車中隊（22両×単価）の車種変更自動計算、架空戦車開発（T-54/IS-4出禁チェック付き）。
   - 海軍艦艇・船団、空軍機体・核兵器（B-29必須）、施設（軍港500億等）の調達と100%全額返金解体。
   - Discordの自国スレッドにそのまま貼れるMarkdownテキスト一発出力機能。
4. **📜 外交条約・講和・国際ニュース**
   - 不可侵条約（1週間）、軍事同盟（1週間・合計4カ国上限）、軍事的通行権、講和条約（賠償金1.8兆→0.9兆→0.4兆・領土1/3割譲・週資金+100億/プロビ）の管理。
5. **🪣 白地図PNGバケツ塗りツール**
   - 手元の白地図PNG画像を読み込んでブラウザ上でバケツ塗りし、PNGとしてダウンロード可能。

## 歴史境界データ

ゲーム用の区画は、歴史境界を既存の地図に合わせて簡略化・調整しています。

- 1914年の欧州国境は Jack Kavanagh の [Map of Europe, c. 1914](https://doi.org/10.5281/zenodo.21341486)（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）を使用しています。
- オーストリア＝ハンガリー帝国の境界は、Antonia Dückelmann と Peter Paul Marckhgott-Sanabria による HistoGIS の [Österreich-Ungarn](https://histogis.acdh.oeaw.ac.at/shapes/shape/detail/9950) を参照しています。原資料と OpenStreetMap への帰属表示は同ページに記載されています。
